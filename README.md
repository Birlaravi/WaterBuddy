Water Buddy

An Android app. Every hour a cute 3D animal walks onto your screen from the bottom right,
over any app, and asks "Have you drunk water?" with Yes / No.
  Yes -> it gets happy: smiling face, jumps, spins, hearts.
  No  -> it gets sad: teary eyes, droopy ears, rain cloud, walks away slowly, asks again in 10 minutes.

Animals: Puppy, Kitten, Bunny, Unicorn, Fox, Piglet, Panda, Penguin, Duckling, Teddy (or random).
They are built in code, so no model files are needed.

Build
  1. Open this folder in Android Studio and let Gradle sync.
  2. Run on a phone (USB debugging) or Build > Build APK(s).
  3. In the app tap: Allow display over other apps, Allow notifications, Remove battery restriction.
  4. Switch "Reminders on". Use "Every 1 minute (test)" to try it, then set it back to 1 hour.
